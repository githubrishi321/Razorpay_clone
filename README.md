# 💳 Razorpay Landing Page Clone

A responsive clone of the **Razorpay** landing page built using **HTML** and **CSS**. This project focuses on frontend development, replicating the look and feel of the Razorpay website for learning purposes.

---

## 🚀 Features

- 📱 Fully responsive layout
- 🎨 Pixel-perfect design inspired by Razorpay
- 🧩 Clean, semantic HTML
- 💅 Organized and modern CSS (Flexbox + Media Queries)
